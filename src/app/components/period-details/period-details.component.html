Média Aritmética com Exame
Quando a disciplina utiliza média aritmética, a média final é calculada com base nas notas dos períodos da matéria. Caso o estudante realize o exame, a menor nota obtida anteriormente é desconsiderada no cálculo da média final.
Média Ponderada com Exame
Quando a disciplina utiliza média ponderada, a média final é calculada considerando os pesos de cada período. Caso o estudante realize o exame, a nota do exame é combinada com a média obtida anteriormente, gerando uma nova média final.
